# esp32-led-chaser
My first ESP32 project using 4 LEDS.
## Components
- ESP32
- 4 LEDs
- 4 × 1KΩ resistors
- Breadboard
- Jumper wires

## Pin Configuration
- LED 1 → GPIO 18
- LED 2 → GPIO 2
- LED 3 → GPIO 23
- LED 4 → GPIO 5

## How It Works
The LEDs turn on one at a time in sequence.
Each LED stays on for 200 milliseconds.
